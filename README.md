# YouTube Clone (React)

A YouTube-style video app built with React. Browse videos, search, filter by category, and watch videos inside the app.

## Live Demo
https://nandu-1108.github.io/youtube-clone-react/

## Features
- Video grid with thumbnails, channel names, and view counts
- Search videos by title or channel name
- Category filters (All, Coding, Music, Gaming, Sports)
- In-app video player with an embedded YouTube player
- Related videos list beside the player
- Client-side routing with React Router

## Tech Stack
- React 19
- React Router
- Vite
- CSS
- React Icons
- Git, GitHub, and GitHub Pages (hosting)

## Run Locally
```bash
git clone https://github.com/nandu-1108/youtube-clone-react.git
cd youtube-clone-react
npm install
npm run dev
```
Then open the local URL shown in the terminal (usually http://localhost:5173).

## Deployment
```bash
npm run deploy
```
This builds the app and publishes it to the `gh-pages` branch.
